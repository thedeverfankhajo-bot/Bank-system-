# BankSystem — سیستم بانک برای بدراک

پلاگین مستقل بانک و کیف پول برای سرورهای Minecraft Bedrock که از PocketMine-MP API 5 استفاده می‌کنند.

## امکانات

- کیف پول جدا از موجودی حساب بانکی
- پنل بومی Bedrock با داشبورد رنگی و دکمهٔ تازه‌سازی موجودی، تاریخچهٔ صفحه‌بندی‌شدهٔ تراکنش‌ها، رتبه‌بندی، انتقال و ابزارهای مدیریتی مجوزمحور
- تأیید نهایی در پنل پیش از انتقال به بازیکن یا تغییر مدیریتی موجودی
- واریز، برداشت و انتقال پول به بازیکن آنلاین
- رتبه‌بندی موجودی بانک و مشاهده سابقه تراکنش‌ها
- دستورات مدیریتی با مجوز مخصوص اپراتور
- ذخیره دائمی در SQLite و ثبت سوابق تراکنش
- محدودکردن دسترسی فایل پایگاه‌داده و فایل‌های جانبی موجود SQLite به مالک فایل در سیستم‌های POSIX
- API عمومی برای اتصال پلاگین‌های دیگر و رویداد BankTransactionEvent
- محاسبه پول با عدد صحیح در واحد خرد برای جلوگیری از خطای اعشاری
- تست‌های خودکار و CI در GitHub Actions

## نیازمندی‌ها و نصب

- PocketMine-MP API 5.0.0 یا جدیدتر از شاخه 5.x
- PHP 8.1+ و افزونه sqlite3

با دستور `/bank` یا `/bank panel` پنل بومی داخل بازی باز می‌شود. این پنل از فرم‌های خود PocketMine-MP استفاده می‌کند و به پلاگین FormAPI جداگانه نیاز ندارد.

برای توسعه، پوشه پلاگین را با DevTools داخل پوشه plugins قرار دهید. برای انتشار، از DevTools برای ساخت PHAR استفاده کنید و فایل BankSystem.phar را در plugins بگذارید. پس از اولین اجرا، تنظیمات در plugin_data/BankSystem/config.yml و پایگاه داده در plugin_data/BankSystem/bank.sqlite3 ایجاد می‌شوند.

## دستورات

| دستور | کاربرد |
|---|---|
| /bank یا /bank panel | بازکردن پنل تعاملی بانک داخل بازی |
| /bank balance | نمایش کیف پول، حساب بانک و مجموع |
| /bank deposit <مبلغ> | واریز از کیف پول به بانک |
| /bank withdraw <مبلغ> | برداشت از بانک به کیف پول |
| /bank pay <بازیکن> <مبلغ> | انتقال پول کیف پول به بازیکن آنلاین |
| /bank top | ۱۰ حساب با بیشترین موجودی بانک |
| /bank history [صفحه] | مشاهده سوابق تراکنش |
| /bank admin give <بازیکن> <wallet/bank> <مبلغ> | افزودن موجودی توسط مدیر |
| /bank admin take <بازیکن> <wallet/bank> <مبلغ> | کم‌کردن موجودی توسط مدیر |
| /bank admin set <بازیکن> <wallet/bank> <مبلغ> | تنظیم موجودی توسط مدیر؛ صفر مجاز است |

مجوز banksystem.admin به‌صورت پیش‌فرض برای اپراتورها فعال است. مبالغ باید حداکثر دو رقم اعشار داشته باشند. در حالت عادی مبلغ باید مثبت باشد. وضعیت محدودیت زمانی تراکنش هر بازیکن هنگام خروج او از سرور پاک می‌شود.

## تنظیمات

فایل resources/config.yml شامل نماد پول، موجودی اولیه، سقف تراکنش و زمان انتظار میان تراکنش‌هاست. اعداد پولی در YAML به شکل متن نقل‌قول‌شده ذخیره شده‌اند تا هنگام خواندن تنظیمات گرد نشوند.

## API

سرویس با Main::getBankService() دریافت می‌شود. مبلغ‌ها در API به صورت واحد خرد عدد صحیح هستند؛ مثلاً 1250 برابر با 12.50 است. برای جلوگیری از ثبت حساب‌های تکراری، کلید حساب UUID بازیکن است نه نام قابل تغییر او.

هر تراکنش موفق همراه با رکورد حسابرسی داخل یک تراکنش SQLite ثبت می‌شود. روی سیستم‌های POSIX، پلاگین برای فایل پایگاه‌داده و فایل‌های جانبی موجود مجوز دسترسی فقط برای مالک (0600) اعمال می‌کند؛ در ویندوز باید ACLهای سیستم فایل مناسب باشند. پس از commit، رویداد BankTransactionEvent اجرا می‌شود؛ این رویداد پس از ثبت نهایی اجرا می‌شود و برای لغو تراکنش نیست.
